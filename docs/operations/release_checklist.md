# QRSIP — Release checklist
#
# Use this checklist when preparing a release.
#
# 1. All tests pass: make test
# 2. Format, lint, typecheck pass: make format lint typecheck
# 3. Security checks pass: make security
# 4. CI is green on main
# 5. PROJECT_STATUS.md updated
# 6. CHANGELOG.md updated
# 7. Version bumped in pyproject.toml
# 8. Release tag created
# 9. Fresh-environment verification performed
# 10. Release notes prepared
